# Milestone record

Each entry: what passed, the numbers, the seeds and params used, anything deferred, and the golden hash committed with it.

## M0 — Skeleton

- Workspace with `hinterlands-core`, `hinterlands-mapgen`, `hinterlands-cli`, `hinterlands-web`. `core` depends on `rand`, `rand_chacha`, `serde`, `bincode`, `libm` only; no I/O.
- `Terrain` and `State` as separate struct-of-arrays; `Params` generated by one macro with a field listing for the UI; `Snapshot` with bincode bytes and FNV hash; `step_year` calling the six systems in order; event queue type (empty).
- CLI: `run`, `validate`, `render` (PNG), `bench`, `hash`, `params`, ground-truth scoring.
- Viewer: egui via eframe 0.37 (trunk), `ViewState` + `Msg` + `update`, `Layer` and `Panel` traits, `SimHandle`, camera module. Loads in headless Chromium with no console errors and draws the map.
- Checks: `just test` passes (same seed → same snapshot; map generation deterministic; golden hash). Browser self-test (`?selftest=200`) matches the native hash `44e95a4b8f197a6e` after fixing D6.
- The systems were written alongside the skeleton; they are checked one at a time in M1–M4.
- Golden hash (map 1, seed 1, defaults, 500 years): see `crates/hinterlands-cli/tests/golden.txt`.
